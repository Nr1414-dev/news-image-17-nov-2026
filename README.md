A deterministic Node 22 program (standard library only) that draws a 1024x1024 newspaper front page summing up Tuesday 17 November 2026's world news — the Gulf, the Kerch Bridge, Gaza, Yemen, COP31 and more — as one PNG image.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
